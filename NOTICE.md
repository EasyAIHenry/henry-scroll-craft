## Carried over unchanged

| File | What it does |
|---|---|
| `engine/scrollcraft.js` | The scroll engine: acts, scrubbing, pinning, panning, reduced motion |
| `engine/scrollcraft.css` | The engine's base styles and theme variables |
| `scripts/encode.sh` | Encodes a clip with dense keyframes so it scrubs smoothly |
| `scripts/serve.mjs` | Local static server for checking the page |
| `scripts/shoot.mjs` | Scrolls the page headlessly, screenshots it, reports dead scroll and contrast |
| `scripts/workspace.mjs` | Finds or creates the folder where builds live |
| `templates/FINGERPRINTS.md` | Empty registry the workspace is seeded with |
| `references/devices.md` | The engine's scroll devices and their attributes |
| `references/verify.md` | The full verification procedure |
| `references/taste.md` | The design floor: spacing, type, colour, contrast |
| `references/template.html` | Starting HTML skeleton |
| `references/device-diag.html` | Diagnostic page for phone-only bugs |

These files still mention a few files that are not in this repository
(`assets.md`, `feel.md`, `uniqueness.md`, `worldflight.md`,
`approved-collection.md`, `kie.mjs`, and `EXAMPLES.md`). They live in Nate's
original repository linked above.

## Carried over with changes

| File | Change |
|---|---|
| `scripts/doctor.mjs` | Removed the kie.ai key check and the `--probe` balance call, because `kie.mjs` is not shipped. The clip is generated by the user on their own video model. Every other check is unchanged. |
